## En curso al pausar: D-WIN

`job-32` detenido durante el build de la imagen. Lo hecho:

- `~/educonect-dev-env/Dockerfile.win` — mingw-w64 + target `x86_64-pc-windows-gnu`, **sin** bibliotecas de ZIM.
- Servicio `win` en `compose.yaml`, target propio, repo en solo lectura.

**Para reanudar:**

```bash
cd ~/educonect-dev-env
export RUST_VERSION=1.88.0 EDUCONNECT_REPO=/home/x/Documentos/EduconetV2
docker compose build win
docker compose run -T --rm win bash -lc \
  'cd /workspace/edu-conect-rural-server && cargo build --locked --release --target x86_64-pc-windows-gnu'
```

Riesgo principal: `rusqlite` con `bundled` compila SQLite desde C bajo mingw.

**Windows está disponible** en WinBoat: RDP en `127.0.0.1:47300`, usuario `pc`, disco de 56 G instalado, y `/home/x` montado como `/shared`. No hay WinRM, así que ejecutar el `.exe` dentro de la VM requiere RDP interactivo.
